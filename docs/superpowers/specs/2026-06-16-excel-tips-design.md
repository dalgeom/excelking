# 엑셀 꿀팁(Excel Tips) 기능 설계

작성일: 2026-06-16
상태: 설계 확정, 구현 대기

## 1. 배경·목적

직장인이 엑셀로 일하다 "이거 어떻게 하지?", "이 단축키가 뭐였더라?" 하면 네이버·구글·유튜브를 검색한다. 이 수요를 엑셀왕 안으로 가져온다. 사무를 보며 **옆에 엑셀왕 한 페이지만 띄워놓으면** 단축키·함수·상황별 해결법을 즉시 찾아볼 수 있게 한다.

부수 효과: 원본 콘텐츠가 늘어나 SEO·AdSense 승인에 유리하다(엑셀왕의 실제 수익 목표).

## 2. 핵심 원칙·제약 (확정)

- **콘텐츠는 에이전트가 통째로 생성**하는 원본 글. 사용자 손품 거의 없음.
- **저작권 안전**: 남의 블로그 글·스크린샷·유튜브 영상 복붙 금지. 전부 새로 작성. (MS 아이콘 교훈과 동일 기준)
- **비용 0 / 서버 없음 / DB 없음**: 꿀팁은 프로젝트 안의 데이터 파일(`tips.ts` 등). 이미지가 필요하면 `static/`에 정적 파일로(CF Pages 무료 CDN). 현재 스택(SvelteKit + adapter-cloudflare, 전부 클라이언트 처리) 유지.
- **시각자료 전략**: 진짜 엑셀 스크린샷 대신 **엑셀풍 HTML 예제 표**를 1차 시각자료로 쓴다. 사이트가 이미 엑셀 테마라 셀·수식줄·강조를 HTML로 그리면 스크린샷보다 화질·테마 일치·저작권 면에서 우월하고, 에이전트가 직접 생성 가능하다. 진짜 스크린샷/GIF는 선택적으로 나중에 추가.
- **응답·콘텐츠 한국어**, 기술용어(함수명·단축키)는 영어 원문 유지. 한글 `word-break: keep-all`(excel.css에 이미 적용).

## 3. 화면·라우트 구조

| 라우트 | 역할 |
|--------|------|
| `/tips` | 목록 페이지. 상단 고정 검색창 + 카테고리 칩 + 꿀팁 카드 그리드. 타이핑 시 즉시 필터. |
| `/tips/[slug]` | 상세 페이지. 꿀팁 1개당 고유 URL(SEO·AdSense에 유리 — 색인 페이지 수 증가). |

- 상단 `SheetTabs`에 **"꿀팁"** 탭 추가: 홈 · 비교 · 분리 · PDF · 합치기 · 대시보드 · 꿀팁.
- `Footer` 사이트맵에 꿀팁 링크 추가.
- `tools.ts`(도구 5종 정의)는 변경하지 않음 — 도구와 꿀팁은 별개 개념.

## 4. 카테고리 (6종)

사무직 실수요 기준. 카테고리는 칩으로 노출하고, 검색과 병행한다.

1. **함수·수식** — VLOOKUP, IF, SUMIF/SUMIFS, COUNTIF, INDEX/MATCH, XLOOKUP 등
2. **단축키** — 자주 쓰는 단축키 모음·치트시트
3. **데이터 정리** — 중복 제거, 텍스트 나누기, 빈칸 채우기, 정렬·필터
4. **서식** — 조건부 서식, 표시 형식, 셀 병합 대안
5. **피벗·집계** — 피벗 테이블, 부분합
6. **자주 겪는 문제** — "날짜가 숫자로 보여요", "### 표시", "자동으로 안 더해질 때" 등 상황별 해결

## 5. 데이터 모델

도구 정의(`tools.ts`)와 같은 방식으로 꿀팁을 데이터 파일에 둔다(예: `src/lib/tips/tips.ts`, 양이 많아지면 카테고리별 파일로 분할).

```ts
interface Tip {
  slug: string;          // URL용 식별자. 예: 'vlookup'
  title: string;         // "VLOOKUP으로 다른 표에서 값 가져오기"
  category: string;      // 카테고리 칩 (위 6종 중 하나)
  keywords: string[];    // 검색용. 예: ['브이룩업','찾기','참조','vlookup']
  summary: string;       // 카드/검색결과 한 줄 설명
  when: string;          // "언제 쓰나" — 상황 설명
  steps: string[];       // 따라하기 단계
  formula?: string;      // 복사용 수식. 예: '=VLOOKUP(E2,A:B,2,0)'
  shortcut?: string;     // 단축키. 예: 'Ctrl + Shift + L'
  example?: ExcelExample;// 엑셀풍 미니 예제 표
  related?: string[];    // 관련 꿀팁 slug 목록
}

interface ExcelExample {
  formulaBar?: string;   // 수식줄에 표시할 텍스트
  headers: string[];     // 열 헤더 라벨 (예: ['사번','이름'])
  rows: string[][];      // 셀 값 행렬
  highlight?: [number, number][]; // 노란 강조 셀 좌표 [row, col]
}
```

카테고리는 매직 스트링 대신 상수/유니온으로 관리해 칩·필터·검증이 한 곳을 참조하게 한다.

## 6. 컴포넌트·재사용

- **`<ExcelExample>`** (신규): `ExcelExample` 데이터를 받아 홈 화면 `.sheet` 그리드와 같은 스타일의 셀 표를 그린다. 헤더 행, 셀, `highlight` 좌표에 노란 강조, 선택 시 `formulaBar`를 기존 `FormulaBar` 또는 동일 스타일로 표시. 꿀팁 상세의 핵심 시각자료.
- **`FormulaBar`** (기존 재사용): 목록/상세 상단 머리글에 기존 패턴대로 사용 가능.
- **꿀팁 카드** — 홈 `.cell` / 도구 카드 스타일을 따르는 엑셀풍 카드.
- 단축키 표기는 `<kbd>` 스타일로 통일(신규 최소 스타일).

## 7. 검색 (클라이언트 전용)

- 모든 꿀팁이 빌드 시 번들에 포함된 정적 데이터 → 별도 요청·서버 없음.
- 입력할 때마다 `title` + `keywords` + `summary` + `category`를 대상으로 즉시 필터.
- 1차 구현은 단순 포함(`includes`) 매칭 + 공백 분리 토큰 AND. 한글/영문 혼용 대응을 위해 소문자화·공백 정규화 정도만. (퍼지 검색 라이브러리는 YAGNI — 도입하지 않음.)
- 카테고리 칩 선택과 검색어는 AND로 결합(칩으로 좁히고 검색어로 더 좁힘).

## 8. 콘텐츠 1차 분량

- 1차 출시: **가장 수요 높은 꿀팁 약 20개**(카테고리당 3~4개). 에이전트가 작성.
- 각 꿀팁은 원본. 최소 구성: 제목·요약·언제 쓰나·단계. 가능하면 수식/단축키/예제 표 포함.
- 이후 세션에서 계속 추가(데이터 파일에 항목 추가만 하면 목록·검색·상세 자동 반영).

## 9. SEO·AdSense

- 각 `/tips/[slug]`에 `<svelte:head>`로 고유 `<title>`·`description`(요약 활용). 기존 페이지 패턴 동일.
- 꿀팁 수가 늘수록 색인 페이지·원본 콘텐츠 증가 → AdSense 승인·검색 유입에 직접 기여.

## 10. 테스트

- 검색·필터 로직을 **순수함수**로 분리해 vitest 단위 테스트(기존 70개 테스트 패턴 따름):
  - 검색어 토큰 AND 매칭, 대소문자/공백 정규화, 카테고리 결합 필터, 빈 검색어 시 전체 반환.
- `tips.ts` 데이터 무결성(필요 시): slug 중복 없음, category가 정의된 6종에 속함, related slug가 실재하는지 정도의 가벼운 검증.

## 11. 영향 범위

신규:
- `src/routes/tips/+page.svelte` (목록)
- `src/routes/tips/[slug]/+page.svelte` (상세)
- `src/lib/tips/tips.ts` (데이터; 분할 가능)
- `src/lib/tips/search.ts` (순수 검색 함수) + `search.test.ts`
- `src/lib/components/ExcelExample.svelte`

수정:
- `src/lib/components/SheetTabs.svelte` — "꿀팁" 탭 추가
- `src/lib/components/Footer.svelte` — 사이트맵에 꿀팁 추가

변경 없음:
- `src/lib/theme/tools.ts`, 도구 5종 라우트.

## 12. 범위 밖 (YAGNI)

- 사용자 투고/댓글, 로그인, 서버·DB.
- 외부 블로그·유튜브 콘텐츠 수집/임베드를 메인으로 삼는 것(참고 링크는 예외적 소량만).
- 퍼지 검색 라이브러리, 태그 자동완성, 즐겨찾기 동기화 등.

## 13. 배포

기존 엑셀왕 규칙 준수: 작업 후 `npm run build` + `npx vitest run` → `git add -A && commit` → `git push origin main` → CF Pages 자동배포 확인(라이브 HTML 마커 grep 폴링). 승인 불필요.
