## 1. 컨셉과 목표

excelking은 엑셀 도구 허브다. 정체성을 디자인으로 강하게 드러내기 위해 **사이트 전체를 엑셀 화면처럼** 보이게 한다 (makejpeg.com의 윈도우 XP 테마에서 착안).

**핵심 원칙: "엑셀처럼 보이되, 눌리는 건 전부 진짜 동작."**
가짜 장식(누르면 아무것도 안 되는 리본 탭 등)은 만들지 않는다. 엑셀 UI 요소 중 우리 기능에 매핑되는 것만 채택한다.

| 엑셀 요소 | 우리 기능 매핑 | 동작 |
|-----------|----------------|------|
| 제목표시줄(녹색) | 브랜드/현재 도구명 | 장식(정직 — 원래 안 눌림) |
| 시트 탭(하단) | 도구 네비게이션(허브+5도구) | **진짜 링크** |
| 셀 그리드(허브) | 도구 카드 = 셀 | **클릭 → 도구 이동** |
| 리본/툴바(도구 페이지) | 그 도구의 실제 동작 | **진짜 버튼**(업로드·실행·다운로드·초기화) |
| 이름상자·수식줄 | 현재 상태 표시(선택 열·파일명·행수) | 상태 표시(정직 — 가짜 입력 아님) |
| 행번호·열문자(A/B/1) | 라벨 | 장식(원래 엑셀도 안 눌림) |
| 상태표시줄(하단) | 준비/행수 등 상태 | 장식 |

## 2. 범위

**대상:** 한 번에 전체.
- 공통 **엑셀 크롬**을 공유 레이아웃(`+layout.svelte`) + 공유 컴포넌트로 구현
- **허브**(`/`)를 셀 그리드 화면으로 재구성
- **5개 도구 페이지** 전부에 엑셀 틀 적용(리본 동작 바 + 수식줄 상태 + 시트탭)
- 기존 SEO/FAQ 콘텐츠는 엑셀 "앱" 영역 아래에 그대로 유지(애드센스·SEO 필수)

**범위 밖 (Out of Scope):**
- 기능 로직 변경(파싱·집계·차트 등 순수 로직은 그대로 — 이번은 **표현 계층만**)
- 새 도구·새 기능 추가
- 실제 엑셀 단축키/셀 편집 같은 동작 모사
- 다국어, 다크모드

## 3. 핵심 결정 (브레인스토밍 결과)

| 결정 | 선택 |
|------|------|
| 방향 | 기능형 풀 엑셀 스킨(B) — 죽은 장식 없이 진짜 동작만 |
| 적용 범위 | 한 번에 전체(레이아웃+허브+5페이지) |
| 리본 | 도구별 실제 동작 바로 사용 |
| 콘텐츠 | 엑셀 틀 아래 기존 사용법/FAQ 유지 |

## 4. 아키텍처

표현 계층만 손댄다. 각 페이지의 `<script>` 로직(상태·함수)은 그대로 두고 **마크업·스타일·공통 크롬**만 재구성한다. 중복되던 업로드/다운로드 배관도 이 김에 DRY한다.

**신규/변경 파일:**

| 파일 | 책임 |
|------|------|
| Create `src/lib/theme/excel.css` (또는 `+layout.svelte` 내 `:global`) | 엑셀 디자인 토큰·전역 스타일(녹색·폰트·셀 보더·버튼) |
| Modify `src/routes/+layout.svelte` | 엑셀 윈도우 크롬: 제목표시줄 + (children) + 시트탭 + 상태표시줄. 전역 테마 적용 |
| Create `src/lib/components/SheetTabs.svelte` | 하단 시트 탭(허브+5도구), 현재 경로로 active 판정, 진짜 `<a>` 링크 |
| Create `src/lib/components/Ribbon.svelte` | 도구 동작 바(엑셀 리본 스타일). children 스니펫으로 버튼 받음 |
| Create `src/lib/components/FormulaBar.svelte` | 이름상자(`cell` prop) + 수식줄(`value` prop) 상태 표시 |
| Create `src/lib/excel/download.ts` | `saveBlob(bytes, filename, mime)` — 5개 페이지 중복 다운로드 배관 통합 |
| Modify `src/routes/+page.svelte` | 허브를 셀 그리드 화면으로 재구성(도구=셀, 클릭 이동) |
| Modify `src/routes/excel-compare/+page.svelte` | 리본 동작 바 + 수식줄 + 엑셀 틀 적용, `saveBlob` 사용 |
| Modify `src/routes/excel-split/+page.svelte` | 〃 |
| Modify `src/routes/pdf-to-excel/+page.svelte` | 〃 |
| Modify `src/routes/excel-merge/+page.svelte` | 〃 |
| Modify `src/routes/excel-dashboard/+page.svelte` | 〃 |

**도구 목록(시트탭·허브 공통 소스):** `src/lib/theme/tools.ts`
```ts
export const TOOLS = [
  { href: '/excel-compare', tab: '비교', title: '두 엑셀 명단 비교·대조' },
  { href: '/excel-split', tab: '분리', title: '엑셀 조건별 시트/파일 분리' },
  { href: '/pdf-to-excel', tab: 'PDF', title: 'PDF 표 → 엑셀 추출' },
  { href: '/excel-merge', tab: '합치기', title: '엑셀 합치기' },
  { href: '/excel-dashboard', tab: '대시보드', title: '엑셀 자동 대시보드' }
];
```
SheetTabs와 허브 그리드가 같은 소스를 쓴다(중복 제거).

**페이지 구조(도구 페이지 공통):**
```
+layout: [제목표시줄]  (children)  [시트탭] [상태표시줄]
  page:    <Ribbon> 도구 동작 버튼들 </Ribbon>
           <FormulaBar cell="기준열" value="사번" />
           <본문: 기존 업로드·결과 UI를 엑셀 틀 안에>
           <콘텐츠: 사용법/FAQ (기존 유지)>
```

## 5. 비주얼 시스템

- **색**: 엑셀 그린 `#217346`(주), 진한 그린 `#1d6f42`(호버), 회색 크롬 `#f3f2f1`, 셀 보더 `#e0e0e0`, 헤더셀 배경 `#f3f2f1`, 선택셀 `#e8f5ec`. 기존 파랑(`#1a73e8`)은 엑셀 그린으로 교체.
- **폰트**: `'Segoe UI', 'Pretendard', system-ui` (엑셀 느낌). 한글 word-break:keep-all 유지(전역).
- **요소**:
  - 제목표시줄: 녹색 바, 좌측 "엑셀왕 excelking", 도구 페이지면 우측에 도구명.
  - 시트 탭: 하단 회색 바, 탭은 흰 배경+하단 녹색 보더(active). 가로 스크롤(모바일).
  - 리본 버튼: 흰 배경+회색 보더(보조), 녹색(주 동작). 아이콘(📁▶⤓↺) + 라벨.
  - 수식줄: 이름상자(보더 박스) + `fx` + 값 텍스트.
  - 셀 그리드: 얇은 보더, 헤더(A/B/C, 1/2) 회색.
  - 상태표시줄: 옅은 회색, 작은 글씨("준비 · 도구 5개" 등).
- **반응형**: 시트탭 가로 스크롤, 리본 wrap, 허브 그리드 stack. 고정 height 금지(min-height).

## 6. 페이지별 적용

- **허브(/):** 셀 그리드. 도구 5개를 셀(A1·B1·C1·A2·B2)로, 클릭 시 이동. 이름상자/수식줄에 호버/선택 도구 설명. 상단 한 줄 리드.
- **비교:** 리본 = `📁파일 A`·`📁파일 B`·`▶비교 실행`·`⤓결과 다운로드`. 수식줄 = 기준열 값. 본문 = 기존 업로드/요약/결과.
- **분리:** 리본 = `📁파일`·`▶분리`·`⤓시트 다운로드`·`⤓ZIP 다운로드`. 수식줄 = 분리 기준 열.
- **PDF→엑셀:** 리본 = `📁PDF 열기`·`⤓엑셀 다운로드`. 수식줄 = "N페이지 · 표 추출됨". 본문 = 미리보기 표.
- **합치기:** 리본 = `📁파일 추가`·`▶합치기`·`⤓다운로드`. 수식줄 = "N개 파일 · M행". 본문 = 파일 목록·출처 체크박스.
- **대시보드:** 리본 = `📁엑셀 열기`·`➕차트 추가`·`📷PNG 저장`. 수식줄 = 감지 요약(숫자/날짜/범주 수). 본문 = KPI·차트.

각 도구의 기존 동작 함수(onUpload/run/download 등)를 리본 버튼에 그대로 연결한다. 로직 변경 없음.

## 7. 에러 / 엣지

기능 로직 미변경이라 신규 에러 없음. 표현상 주의:
- 리본 버튼은 상태에 따라 비활성/숨김(예: 결과 없으면 다운로드 비활성) — 기존 `{#if}` 조건 재사용.
- 콘텐츠가 긴 페이지에서 엑셀 틀(시트탭·상태표시줄)은 화면 하단 고정이 아니라 문서 흐름상 앱 영역 끝에 둔다(스크롤되면 콘텐츠가 이어짐). 단순·안전.
- 모바일에서 시트탭 잘림 방지(가로 스크롤).

## 8. 테스트 / QA

이번은 표현 계층 변경이라 **새 단위 테스트 없음**. 검증:
- `npm test` — 기존 70개 그대로 통과(로직 무변경 확인).
- `npm run check` 0 errors, `npm run build` 성공.
- **browse 수동 QA(필수)**: 허브 + 5개 도구 페이지 각각 — (1) 엑셀 틀 렌더, (2) 시트탭 네비게이션 동작, (3) 각 도구의 핵심 동작(업로드→실행→다운로드)이 리본에서 그대로 작동, (4) 콘솔 에러 0, (5) 스크린샷으로 외형 확인.
- 회귀 주의: 기존 기능(파일 처리·다운로드)이 마크업 재구성 후에도 동작하는지 페이지마다 확인.
